#  Regional Sales Analysis

##  Project Overview
This project focuses on analyzing regional sales data to uncover valuable business insights using Python and Power BI. The analysis includes data cleaning, exploratory data analysis (EDA), and an interactive dashboard to help stakeholders understand sales performance across products, customers, channels, and regions.

---

##  Problem Statement
Businesses generate large volumes of sales data but often struggle to identify trends, high-performing products, profitable customers, and regional performance. This project aims to transform raw sales data into meaningful insights through data analysis and visualization, enabling data-driven business decisions.

---

##  Dataset
The dataset contains regional sales information, including:
- Order Details
- Customer Information
- Product Information
- Sales Channel
- Revenue
- Cost
- Profit
- Profit Margin
- Region & State

---

##  Dashboard Features
- Total Revenue, Profit & Profit Margin KPIs
- Monthly Sales Trend
- Top 10 Products by Revenue
- Top & Bottom 10 Customers
- Sales by Channel
- Sales by US Region
- Top States by Revenue
- Top States by Profit
- Interactive Filters (Slicers)

---

##  Key Business Insights
- Identified the highest revenue-generating products.
- Analyzed top-performing customers based on revenue.
- Compared sales performance across different sales channels.
- Evaluated regional sales distribution across the US.
- Measured profitability using profit and profit margin analysis.
- Identified top-performing states based on revenue and profit.

4. Open the Power BI (.pbix) file to explore the interactive dashboard.
